# Interactive Piano Keyboard

A browser-based piano keyboard with synthesized sound, note names, and frequencies. It can be installed as a Progressive Web App (PWA) and used offline on iOS, Android, and desktop browsers.

## Use online

Visit [constHarmony.github.io/piano](https://constharmony.github.io/piano/), enable audio, and play the keys.

## Install for offline use

Open the site once while connected to the internet, then:

- **iPhone/iPad:** In Safari, choose **Share → Add to Home Screen** and enable **Open as Web App**.
- **Android:** In Chrome, choose **Install app** or **Add to Home screen**.
- **Desktop:** Use the browser's **Install** option when available.

Launch the installed app once while online to ensure its files are cached. Audio must be enabled after each launch due to browser autoplay restrictions.

## Hosting

The app is self-contained and can be hosted as a static site. GitHub Pages can publish it directly from the repository root.
